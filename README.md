# void·labs 个人主页
> 技术向个人作品集网站，使用原生 HTML / CSS / JavaScript，无第三方框架。
GitHub Pages 自动部署。

### 文件结构
- `index.html` 网站入口页面
- `style.css` 全部样式
- `script.js` 交互逻辑（粒子、打字机、滚动动画、数字计数等）

### 本地预览
直接打开 index.html 即可，不需要本地服务器。

### GitHub Pages部署
1. 将全部4个文件上传仓库根目录
2. Settings → Pages → Source选择 `Deploy from a branch`
3. 分支选 main，文件夹选 `/ (root)`，保存
4. 等待1‑2分钟，访问 `用户名.github.io/仓库名`

### 功能清单
- 粒子动态背景 + 扫描线滤镜
- 代码窗口打字机动画
- 滚动入场动画、数字计数动画
- 导航栏滚动高亮
- 回到顶部悬浮按钮
- 点击复制邮箱
- 全响应式，支持手机/平板/PC
